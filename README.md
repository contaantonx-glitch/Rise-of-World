# World Dominion

Prototype de jogo RTS/4X offline em Godot 4 para Windows.

## Como abrir

1. Instale o Godot 4.
2. Abra a pasta do projeto.
3. Abra `project.godot`.
4. Pressione F5 para executar.

## O que está implementado

- HUD com recursos
- Economia básica
- Construção de prédios
- Cidade em mapa 2D
- Salvamento local em disco
- Sistema de progresso inicial

## Objetivo do protótipo

Criar uma base funcional para um jogo de estratégia offline, com identidade própria inspirada em jogos de domínio territorial e gestão de impérios.

## Controles

- Botões na UI para construir
- Botão "Salvar" para gravar progresso
- Botão "Carregar" para restaurar o arquivo salvo
